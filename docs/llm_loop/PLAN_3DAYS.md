# LLM 품질 정상화 3일 계획

## 작업 원칙

- 작업 저장소는 `C:\National_Assembly_3` 하나만 사용한다.
- 기존 평가 데이터와 기존 평가 코드는 새 품질 점수 계산에 사용하지 않는다.
- 현재 `/query` 시스템은 수정 전 기준점 측정을 위한 대상으로만 사용한다.
- 원문 PDF와 데이터베이스를 정답의 출처로 사용한다.
- RRF 수정은 이번 3일 범위에서 제외한다.
- 실행 결과와 증거 파일이 있어야 작업을 `DONE`으로 표시한다.
- 계획에 없던 문제는 `NEW-번호`를 붙여 `STATUS.md`에 추가한다.

## 상태 규칙

| 상태 | 뜻 |
|---|---|
| `TODO` | 시작하지 않음 |
| `DOING` | 현재 작업 중 |
| `DONE` | 구현과 검증 및 결과 저장 완료 |
| `NEW` | 실행 중 새로 발견된 수정 또는 재검토 항목 |
| `BLOCKED` | 외부 조건 때문에 진행할 수 없음 |
