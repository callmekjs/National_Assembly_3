# 블라인드 문항 작성 외부 전송 승인 안내

## 현재 상태

사용자가 2026-08-18에 OpenAI API(`gpt-5.6-sol`)로 새 회의록 원문 120건을
전송하고 총 API 비용을 $10 이내로 제한하는 것을 명시적으로 승인했다. 전송과 문항
작성은 완료됐으며 실제 작성 비용은 $2.358480, 전체 누적 비용은 $9.806811이다.

## 승인 시 전송되는 내용

- 대상: 개발문제와 원문이 겹치지 않는 회의록 청크 120건
- 필드: 날짜, 위원회, 발언자, 직책, 회의록 원문
- 제외: API 키, 사용자 개인정보, DB 접속정보, 애플리케이션 로그
- 목적: 블라인드 답변 가능 90문항과 예비 30문항의 질문·정답·필수/금지 주장 작성
- 모델: `gpt-5.6-sol` (high/medium의 출력 절단 실패를 보존하고 최종 120건은 low로 완료)
- 추가 비용 상한: 별도 실행 인자로 제한하며 전체 승인액 $10을 넘기지 않음

## 전송 후에도 자동 통과하지 않는 이유

작성 결과는 원문·메타데이터·숫자 일치 자동검사를 거쳤다. 130문항은 Codex가 원문을
독립 검토했으며, 이 검토를 사람 검수라고 주장하지 않는다. 최종 데이터는 동결했다.

## 당시 사용한 승인 문구

`블라인드 문항 작성을 위해 새 회의록 원문 120건을 OpenAI 모델로 전송하는 것을 승인한다. 기존 총 API 한도 10달러는 유지한다.`

## 2차 블라인드 승인(2026-08-18)

사용자는 다음 문구로 신규 원문·평가답변 전송과 추가 비용을 승인했다.

`새 블라인드 평가를 위해 신규 회의록 원문과 평가 답변을 OpenAI API에 전송하는 것을 승인한다. 추가 비용 한도는 $6이다.`

누적 관리 상한은 $16으로 표시하되, 2차 루프는 승인 시점의 실제 누적액
$9.806811을 기준으로 **추가 지출 $6**을 별도로 검사한다. 따라서 2차 루프가 사용할 수
있는 실질 상한은 누적 $15.806811이며, 이전 한도의 미사용액을 새 승인액에 더하지 않는다.
