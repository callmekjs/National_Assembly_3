## 실제로 고친 문제

- 답변에만 있고 인용 전문에는 없는 숫자를 문장 단위로 차단한다.
- 인용 전문에 없는 인물 이름과 직함 조합을 차단한다.
- 치명적 오류는 주변 보조 문맥을 제거하고 high 추론으로 한 번만 다시 생성한다.
- 재생성도 실패하면 잘못된 답을 내보내지 않고 거절한다.
- 여러 금액을 임의로 더하거나 배분 관계를 만들어내지 않도록 프롬프트를 강화했다.
- 지자체와의 이견을 지자체 간 이견으로 바꾸는 관계 방향 왜곡을 금지했다.
- 경제지표 비교와 정당 진영 비교를 분리했다.
- 답변 기본 추론을 low에서 medium으로 올렸다.
- 공식 API 단가보다 낮게 잡힌 비용 장부를 수정했다.

## 점수에서 제외한 문항

`dev-002`, `dev-011`, `dev-019`, `dev-020`은 답변을 본 뒤 유리하게 제외한 것이 아니다.
질문이 요구하지 않은 배경·후속 질문·개별 사례를 정답표가 필수로 요구한 루브릭 결함이며,
동일 제외 기준을 수정 전과 수정 후에 똑같이 적용했다. 원본 결과는 삭제하지 않았다.
